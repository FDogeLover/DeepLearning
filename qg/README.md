# QG — 图像特征提取与相似度匹配

基于深度学习特征向量的图像相似度匹配系统，包含 GUI 应用。

- `extract_features.py` — 特征提取（单线程）
- `extract_features_multi.py` — 特征提取（多线程）
- `gui_similarity_app.py` — 相似度匹配 GUI
- `class_based_gui.py` — 基于分类的 GUI
- `build_feature_db.py` — 构建特征数据库
- `build_feature_centers.py` — 构建聚类中心
- `model.py` / `model2.py` / `model3.py` — 模型定义
- `train_from_ndjson.py` — 从 ndjson 训练
